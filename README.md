# SellAuth Integration (Rust)

A simple guide for integrating SellAuth with a Rust project.

This guide is for **Rust only**.

## Hosted integration (recommended)

If you want the easiest setup, you can also use **Cloop's hosted integration**. It supports Rust and is the recommended option if you don't want to handle the integration yourself.

- SellAuth integration guide: https://docs.skinloop.io/integrations/sellauth

## Rust setup

1. Open the [SellAuth integration guide](https://docs.skinloop.io/integrations/sellauth).
2. Follow the setup and configuration steps that apply to your SellAuth project.
3. Add the required configuration to your Rust application.
4. Test the integration before using it in production.

> **Note:** Refer to the official guide for the exact configuration values and current implementation details. This README intentionally focuses on Rust and does not include instructions for other languages.

## Which option should I use?

- **Cloop hosted integration:** Recommended for the simplest setup and less maintenance on your side.
- **Your own Rust integration:** Use this if you want to manage the integration directly in your Rust project.

## Official documentation

For the full setup instructions and the latest details, see the [SellAuth integration documentation](https://docs.skinloop.io/integrations/sellauth).
