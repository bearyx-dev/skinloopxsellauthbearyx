# SellAuth X [Skinloop](https://skinloop.io/)

A simple guide for integrating SellAuth with [Skinloop](https://skinloop.io/)

## Hosted integration (recommended) 10 times easier

If you want the easiest setup, use **Skinloop hosted integration** [find it here](https://skinloop.io/dashboard/integrations). It supports Rust and CS2 is the recommended option if you don't want to handle the integration yourself.








## Or do it yourself then here but rust only if you do it yourself

1. Open the [SellAuth integration guide](https://docs.skinloop.io/integrations/sellauth).
2. Follow the setup and configuration steps that apply to your SellAuth project.
3. Add the required configuration to your Rust application.
4. Test the integration before using it in production.

## Which option should I use?

- **Skinloop hosted integration:** Recommended for the simplest setup and less maintenance on your side.
- **Your own Rust integration:** Use this if you want to manage the integration directly in your Rust project.

## Official documentation

For the full setup instructions and the latest details, see the [SellAuth integration documentation](https://docs.skinloop.io/integrations/sellauth).
